# Sistema de Gestão de Biblioteca

## Objetivo do Sistema
O Sistema de Gestão de Biblioteca tem como objetivo automatizar e centralizar o controle de acervo,
empréstimos, reservas e gestão de usuário, garantindo a aplicação correta das regras de negócio como
limites de empréstimos simultâneos e cobrança de multas por atraso.

## Principais Funcionalidades
**Gestão de usuários**: cadastro e diferenciação entre leitores e bibliotecários;
**Controle de acervo**: suporte para livros físicos e livros digitais (e-books);
**Gestão de empréstimos**: validação de limite de livros por usuário e cálculo automático de datas de devolução;
**Regras de negócio e travas**: bloqueio de novos empréstimos para usuários com pendências de multas ativas;
**Sistema de reservas**: fila de espera para títulos indisponíveis no momento;
